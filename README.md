# REST API для платформы онлайн-тестирования

Лабораторная работа по дисциплине «Интернет-технологии и веб-программирование».

## Описание

REST API для управления тестами и результатами их прохождения. Реализованы CRUD-операции, обработка ошибок и генерация сертификатов.

## Технологии

- Node.js
- Express.js
- Nodemon (для разработки)
